# 🎓 FIU Club Recommendation  

## 💡 Inspiration  
There are many clubs at FIU, which can make it daunting for students to decide which one to join. We wanted to make that process easier by building a system that recommends clubs based on each student’s unique responses and interests.

---

## ⚙️ What It Does  
The application recommends clubs based on user responses. Students answer a few short questions, and the system suggests clubs that align with their preferences, helping them get involved more easily on campus.

Website: https://ana-ruth.github.io/club-quiz/

---

## 🛠️ How We Built It  
We built the project using several tools and technologies:  
- **Frontend:** HTML, CSS, and JavaScript  
- **Backend:** Python and FastAPI  
- **Databases:** MS SQL and MySQL  

The front end was designed to collect user input, the backend handled data processing through the API, and the databases stored club and user information.

---

## 🚧 Challenges We Ran Into  
We faced many challenges since it was our first time participating in a hackathon. One of the biggest issues was connecting the **front end** to the **backend**, and the **backend** to the **database**. After several debugging attempts, we managed to resolve most of these issues.  

However, due to limited time, the last major task—**matching the database information to student responses**—was left incomplete. This was the only remaining step before full functionality.

## 🔮 What’s Next for FIU Club Recommendation  
Our next step is to fix the remaining issue of matching the databases to the actual responses from students. Once this is completed, the project will be fully functional and ready for real use by students at FIU.
